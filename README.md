# Black Blade Telegram Bot

⚡ Multi-feature Telegram bot

## Features
- 🤖 AI Chat
- 🎨 Sticker Maker
- 📥 TikTok & Instagram Downloader
- 🎤 Voice Note Transcription
- 🎮 Fun & Games
- 🌤 Weather
- 🧮 Calculator
- 📱 QR Code Generator

## Deploy on Railway

1. Create new project on Railway
2. Connect this GitHub repo
3. Set env vars:
   - `BOT_TOKEN` = your Telegram bot token
   - `OWNER_ID` = your Telegram user ID (optional)
   - `DEEPGRAM_KEY` = for voice transcription (optional)
4. Deploy!
